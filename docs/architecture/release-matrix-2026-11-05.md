# Replacement requirements and representative traces

Companion to the [source review](release-review-2026-11-05.md) and [dispatch packages](release-backlog-2026-11-05.md). Numbering F01–F17 follows §8 of the owner-approved completion plan. The rows are representative. Each inventory instruction below is part of **L / issue 18**, and produces individually closable rows for the worker named. Further inventory is mandatory for every family.

**How to use the traces.** Paths are relative to [app](../../crates/benilla-app/src), [UI](../../crates/benilla-ui/src/script), [wire](../../crates/benilla-protocol-wrath/src), and AC `D:/WOW/WM_BridgeLab/src/azerothcore/src/server/game/Handlers`. For world commands the common real path is UI/input → `NetCommands` → [wrath.rs::wrath_tap_commands](../../crates/benilla-app/src/wrath.rs) → bounded `WrathOutbound` → `run_session_with_cancel` → `world.rs::send`. Incoming packets go to `SessionState::reduce` for world fields and/or `gameplay::parse` → `translate_gameplay` → scoped `wrath_dispatch_events` for event consumers; digests reach `wrath_net_drain` → `wrath_apply_world`. A producer alone does not cross a missing adapter. Each trace identifies deviations from this common path.

**Evidence.** PARTIAL means source for part of the representative path. BROKEN identifies a particular missing or lossy edge. UNKNOWN means an integrated path was not established. Each *gate* is a required future observation on one identified candidate. Record admission, opcode/family, server response or refusal, epoch/world, owner delta, displayed result and durable re-read. If no suitable diagnostic exists, add a redacted stage at the first missing boundary. Local-only behavior has a local writer; a network acknowledgement would be meaningless there.
