## H00 change and source reasoning

Changed only production file `crates/benilla-hotpatch/src/lib.rs`.
Previously `Host::poll` assigned `observed` before parsing/opening. A failed DLL load
therefore made the next identical manifest return early, even if the DLL became available.
It now remembers the manifest after successful staging, or after identifying the already
active digest. Parse/open errors leave the candidate eligible for another poll. The active
module is never replaced by this path; promotion still requires valid pose evaluation.
Successfully staged candidates that fail pose validation remain suppressed as before.

No new timer is needed for the current callers: the Bevy adapter polls once per second
and deduplicates identical error messages; the bounded native probe sleeps 250 ms.
Invalid manifests/load failures will likewise be retried at caller cadence. No exponential
backoff, asynchronous loading or retry performance claim is introduced.
