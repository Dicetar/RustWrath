## Authoritative 12340 sources read

- `AuraApplication::BuildUpdatePacket` (`SpellAuras.cpp:187-218`): u8 slot; u32 spell id (0 for
  removal, ending the block); else u8 flags, u8 caster level, u8 stack-or-charges, a packed
  caster guid unless `AFLAG_CASTER`, and `(max, remaining)` durations when `AFLAG_DURATION`.
- `Player::SendAuraUpdateAll` (`Player.cpp:12053-12063`): packed target guid, then one block per
  visible slot with no count.
- `AuraApplication::ClientUpdate` (`SpellAuras.cpp:220-235`): packed target guid + one block.
- `SpellAuraDefines.h:26-34`: `AFLAG_EFF_INDEX_0..2` 0x1..0x4, `AFLAG_CASTER` 0x08,
  `AFLAG_DURATION` 0x20, `AFLAG_POSITIVE` 0x10, `AFLAG_NEGATIVE` 0x80.
- `Opcodes.h`: `SMSG_AURA_UPDATE_ALL` 0x495, `SMSG_AURA_UPDATE` 0x496.

## Repairs

- The pure reducer gains `ObjectEntry::auras` (slot, spell, flags, level, charges, caster,
  durations), sorted by slot. Blocks apply in packet order; a spell id of 0 removes the slot; a
  recreate clears the aura set with the field slate; identical resends do not count as state
  changes. The 1.12 descriptor has no aura equivalents of caster/durations; they are kept on the
  state for later children.
- `SessionState::reduce` routes both aura opcodes through the same revision counter as the
  update stream, and the Loading window drops them with the other old-scope traffic.
- The digest carries the slot list; the app synthesizes the 1.12 descriptor window
  (`UNIT_FIELD_AURA` 47-94, `AURAFLAGS` 95-100) when it creates or updates a unit, emitting the
  stock watcher's `FieldChanged` edges and one `AuraFieldsChanged` call per changed window.
  12340 slots 48 and up have no 1.12 field and are dropped; the flags' low three bits become
  the AURAFLAGS nibble.
- Auras ride the existing `WrathChanges.updated` path, so no new event channel or owner exists.

## Remaining gaps after this slice

- Aura durations are not yet applied to the 1.12 bar: the stock `SessionEvent::AuraDuration`
  path needs the slot's duration from these blocks (the buffer holds the values; wiring the
  event is a bounded follow-up).
- `SMSG_UPDATE_AURA_DURATION` does not exist in the 12340 table.
- Slots 48+ are outside the 1.12 descriptor and are not displayed.
